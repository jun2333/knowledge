# 算法基础

#### 时间复杂度(渐进时间复杂度)

代码执行时间随数据规模增长的变化趋势

方法：

1.只关注循环次数最多的那行代码

2.加法法则：总复杂度等于量级最大的那段代码复杂度

3.乘法法则：嵌套代码的复杂度等于内外代码复杂度的乘积

#### 空间复杂度(渐进空间复杂度)

内存空间随数据规模增长的变化趋势

#### 四个概念

##### 最好情况时间复杂度、最坏情况时间复杂度、平均时间复杂度、均摊时间复杂度

#### 例子1：查找

```javascript
function find(arr,x){
	let res = -1;
    for(let i=0;i<arr.length;i++){
        if(arr[i] === x){
            res = i;
            break;
        }
    }
    return res
}
```

最好情况下如数组第一个元素就是我们要查找的，所以最好情况时间复杂度是：O(1)

最坏情况下，假设数组长度是n，遍历整个数组都没查找到数据，最欢情况时间复杂度是：O(n)

平均时间复杂度分析：

假设数组长度是n，x在数组中的位置有n+1种情况，每个位置数据与x对比只有等于和不等于2种情况，所以平均时间复杂度计算如下：

1*(1/2n)+2*(1/2n)+...+n(1/2n)+n 

计算出为：O(n)

均摊时间复杂度：O(1)

#### 例子2：插入

```javascript
let arr = new Array(n)
let count = 0
function insert(val){
    if(count === arr.length){
        let sum = 0;
        for(let i=0;i<arr.length;i++){
            sum+=arr[i]
        }
        arr.lenth = 0;//清空数组
        arr[0] = sum
    }
    arr[count] = val
    count++
}
```

最好情况时间复杂度：O(1)

最坏情况时间复杂度：O(n)

平均情况时间复杂度：假设数组长度为n，可分为n种情况外加1种特殊情况，n种情况是0-n位置的时间复杂度O(1)，特殊情况的时间复杂度是O(n)，计算如下

1(1/n+1)+1(1/n+1)+...+1(1/n+1)+n(1/n+1)

计算出为：O(1)

均摊时间复杂度：O(1)
