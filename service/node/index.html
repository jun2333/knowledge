定位：本目录是「Node 服务端」的完整知识体系——面向已经会写前端、想把服务端做扎实的读者。全部读完 + 对照 Java 服务端知识地图 的选型篇，目标是能独立开发业务接口、能说清 Node 的并发模型、能在 Node 和 Java 之间做出合理的技术选型。

读法建议：不要按目录顺序从头读到尾——先读「Node 核心与运行时」三篇建立运行时心智，再按需要进具体框架；「Node 工程化与选型」两篇放在最后（一个讲怎么上线，一个讲该不该用 Node）。

二、三阶段学习路径（照这个走） ​

阶段一：运行时地基（能写对，别踩单线程的坑） ​

  1. Node.js 入门 —— 重点吃透事件循环、模块系统（CommonJS vs ESM）、fs/stream/http 核心 API
  2. Node.js 高并发与高可用设计 —— 搞清楚什么场景下单线程会卡死、什么时候需要 worker_threads / cluster

验收标准：说清一次 HTTP 请求从 socket 到响应的完整链路；解释为什么 CPU 密集任务会阻塞事件循环；写出流式处理大文件的代码而不是 readFileSync。

阶段二：框架实战（能干活） ​

  1. Express.js 入门 —— 中间件范式是后面所有框架的地基
  2. Koa 入门 —— 洋葱模型比 Express 更接近"现代"写法
  3. TypeORM 用法 —— 数据访问层
  4. 按项目需要选：NestJS（中大型/企业级）、Fastify（性能优先）、Egg.js（阿里系）

验收标准：用 Express 写一个带参数校验、错误处理中间件、限流、认证的完整接口；说清 Express 与 Koa 中间件执行顺序的差异。

阶段三：上线与选型（能交付、能决策） ​

  1. Node.js 服务部署最佳实践 —— 进程守护、容器化、优雅退出、发布与回滚
  2. PM2 进程管理 —— 裸机部署的具体工具（注意：容器里通常不用它）
  3. Node.js vs Java 后端选型 —— 和 Java 服务端 对照着看

验收标准：把一个 Node 服务从零部署到服务器（含 Docker、优雅停机、进程守护）；能对着场景说清"这个该用 Node 还是 Java，为什么"。

三、面试速通路线（临阵磨枪用） ​

Node 岗出镜率排序：

  1. 事件循环与异步模型（setTimeout / setImmediate / process.nextTick 的执行顺序，必考）
  2. 模块系统（CommonJS vs ESM、循环依赖、ESM 的提升与惰性求值）
  3. Stream 与背压（为什么大文件必须流式处理）
  4. 进程与线程（worker_threads vs cluster vs child_process 怎么选）
  5. Express / Koa 中间件机制
  6. 内存管理（V8 堆外内存、Buffer 与垃圾回收）

跨栈通用部分（网络协议、数据库、Redis、分布式）见 后端基础。

四、和 Java 侧的关系 ​

这不是"二选一"，而是两条路线各有适用场景：

  • Node 侧强项：I/O 密集（网关、BFF、SSR、实时通信）、从 0 到 1 的业务迭代速度、前端团队直接上手
  • Java 侧强项：CPU 密集与长事务、复杂的企业级中间件生态、成熟的 JVM 生态与可观测性工具链

选型细节见 Node.js vs Java 后端选型。

五、维护说明 ​
