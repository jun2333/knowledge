二、三阶段学习路径（照这个走） ​

阶段一：语言关（能写出"像 Java"的代码） ​

  1. Java 入门 —— 建立静态类型 + 同步阻塞 + 面向接口三大心智
  2. Java 语言进阶 —— 泛型/反射/注解/String 四大件
  3. Java 集合源码 —— 集合是日常工具，先会用再看源码

验收标准：不看书写出 User DTO（record）+ Stream 查询 + Optional 处理；说清 == 和 equals；知道自定义对象当 HashMap key 要重写什么。

阶段二：运行时 + 框架（能干活的核心） ​

  1. JVM 入门 —— 知道内存分区和 GC，能看懂 GC 日志
  2. Java 并发编程 —— 多线程心智 + 线程池 + 常见坑
  3. Spring 核心原理 —— 先懂原理再用框架
  4. Spring Boot 入门 —— 主力篇，反复翻的案头书
  5. 配合 Java 实战计划 阶段 1-4：跑通 mall，写 CRUD，接缓存

验收标准：在 mall 里独立加一个带缓存 + 权限校验的业务接口；说清 IoC/AOP/事务为什么那样设计；画出线程池任务提交流程图。

阶段三：工程化 + 架构（能上线、能面试） ​

  1. Java 服务部署 —— 打 jar、配 JVM、上容器
  2. 高并发高可用设计 —— 缓存三难/限流/容量估算
  3. Java IO/NIO + Netty 入门 —— 网络编程全景
  4. RPC 原理与 Java 生态 —— 服务间调用怎么发生的（Dubbo/gRPC/Feign）
  5. Spring Cloud 微服务 —— 按需（微服务岗必读）
  6. API 网关深入 —— 网关的路由/鉴权/日志怎么落地（微服务岗必读）
  7. 配合 Java 实战计划 阶段 5-7：安全、微服务、部署全流程

验收标准：把一个 Spring Boot 服务从零部署到服务器（含 Docker + nginx + 优雅停机）；面试能讲清"缓存三坑怎么防""线程池参数怎么定""为什么 3 级缓存解循环依赖"。

三、面试速通路线（临阵磨枪用） ​

如果面的是初中级 Java 岗，按出镜率排序：

  1. Java 集合（HashMap 原理是出镜率第一）
  2. Java 并发（JMM/锁/线程池）
  3. JVM（内存分区/GC/类加载）
  4. Spring（IoC/AOP/事务/循环依赖）
  5. MySQL/Redis（见后端基础）
  6. 语言基础（equals/hashCode、泛型擦除、异常体系）

微服务岗追加：Spring Cloud 全家桶 + 分布式（CAP/分布式锁/分布式事务）。

AI 应用岗追加：Java AI 分册（Spring AI + RAG + 工程化）——2025-2026 Java 岗的新加分项。

四、和其他知识的关系 ​

  • Node/TS 经验是优势不是包袱：每篇都用 JS/TS 做了锚点对照，读的时候主动想"这对应 JS 里什么"，比死记快一倍
  • 前端基础（浏览器/网络/安全）在浏览器目录，和 Java 侧的网络编程互为表里
  • 所有篇目的「延伸阅读」互链成网，读到不懂的概念顺着链接跳，别卡住
