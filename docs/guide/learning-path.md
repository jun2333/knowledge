### 学习顺序

**第一阶段: JavaScript 基础**
1. [数据类型与内存管理](/javascript/memory) - ⭐⭐⭐⭐⭐
2. [ES6+ 新特性](/javascript/es6) - ⭐⭐⭐⭐
3. [原型与继承](/javascript/prototype) - ⭐⭐⭐

**第二阶段: DOM 操作**
4. [事件机制](/javascript/event) - ⭐⭐⭐⭐
5. [闭包与作用域](/javascript/closure) - ⭐⭐⭐⭐⭐

**第三阶段: CSS 布局**
6. [CSS 布局概览](/css/layout) - ⭐⭐⭐⭐
7. [Flexbox 布局](https://flexboxfroggy.com/) - 实战练习
8. [移动端适配](/css/mobile-adaptation) - ⭐⭐⭐

**第四阶段: 框架入门**
9. [Vue 双向绑定原理](/vue/reactive) - ⭐⭐⭐⭐⭐
10. [Vue2 生命周期](/vue/lifecycle-v2) - ⭐⭐⭐⭐

## 📊 面试准备时间表

### 2周冲刺计划

**第1-3天: JavaScript 核心**
- 数据类型、闭包、作用域
- 异步编程、Promise
- 事件循环

**第4-6天: 框架原理**
- Vue 响应式、Diff 算法
- React Hooks、Fiber 架构

**第7-9天: 浏览器 & 性能**
- HTTP 协议、渲染机制
- 性能优化策略

**第10-12天: 项目实战**
- 复习大文件上传项目
- 准备项目亮点介绍

**第13-14天: 算法刷题**
- LeetCode Easy 10题
- LeetCode Medium 5题
