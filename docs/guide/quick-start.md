# 快速开始指南

## 🚀 启动文档站点

### 1. 安装依赖

```bash
npm install
```

### 2. 启动开发服务器

```bash
npm run docs:dev
```

访问 `http://localhost:5173` 查看文档

### 3. 构建生产版本

```bash
npm run docs:build
```

### 4. 预览生产版本

```bash
npm run docs:preview
```

## 📖 如何使用这个知识库

### 按主题学习

1. **JavaScript 核心** - 前端开发的基础，面试必考
   - 从数据类型和内存管理开始
   - 理解异步编程机制
   - 掌握闭包和作用域

2. **框架原理** - 深入理解 Vue/React
   - 学习响应式系统
   - 理解虚拟 DOM
   - 掌握组件化思想

3. **浏览器** - 理解页面如何呈现
   - 渲染机制
   - 事件循环
   - 性能优化

4. **实战项目** - 动手实践
   - 大文件上传
   - ServiceWorker 插件
   - 简易浏览器实现

### 按难度学习

**初级** (0-1年经验)
- JavaScript 基础语法
- CSS 布局
- 简单的 DOM 操作

**中级** (1-3年经验)
- 框架使用和原理
- 性能优化
- 工程化工具

**高级** (3年以上经验)
- 源码阅读
- 架构设计
- 复杂问题解决

## 💡 面试准备建议

### 1. 理论 + 实践

每个知识点都要：
- 理解概念
- 能写出示例代码
- 知道实际应用场景

### 2. 深度优先

不要贪多，先深入掌握几个核心知识点：
- JavaScript 内存管理
- Vue 响应式原理
- 浏览器渲染机制

### 3. 总结归纳

用自己的话总结每个知识点，形成知识网络。

## 🔍 搜索技巧

在文档站点中使用 `Ctrl+K` (或点击搜索图标) 打开搜索框：

- 输入关键词快速定位
- 支持模糊搜索
- 可以搜索代码块内容

## 📝 贡献内容

如果你想添加新的知识点：

1. 在 `docs/` 目录下创建对应的 Markdown 文件
2. 在 `docs/.vitepress/config.mts` 中添加侧边栏配置
3. 提交 PR

### 文档模板

```markdown
# 标题

::: tip 面试重要性
⭐⭐⭐⭐⭐ 高频考点
:::

## 核心概念

解释概念...

## 代码示例

```javascript
// 示例代码
```

## 常见面试题

### Q1: 问题描述？

**A:** 回答...

## 总结

关键点总结...
```
