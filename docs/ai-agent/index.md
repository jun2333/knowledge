# AI Agent 工程实践

::: tip 模块说明
本模块聚焦 AI Agent 的工程化实践,重点关注如何用好的模型做好项目。涵盖 Spec-First 开发、AI Harness 工程、Agent 设计模式等进阶主题。
:::

## 🎯 学习目标

通过本模块的学习,你将掌握:

- **Spec-First 开发模式** - 规范优先的 AI 应用开发方法论
- **AI Harness 工程** - 构建可维护、可扩展的 AI 应用架构
- **Agent 设计模式** - ReAct、Plan-and-Execute 等经典模式
- **评估与测试** - 如何衡量和优化 Agent 效果
- **生产环境实践** - 监控、优化、成本控制等实战经验
