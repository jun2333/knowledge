## 一句话概括

一个**本地运行**的个人技术知识库：用 VitePress 承载 250+ 篇技术笔记，用 Koa + LangChain.js 把笔记做成向量索引，接本地 Ollama 模型实现**带引用溯源**的自然语言问答。

全部跑在本机，不联网、零 API 成本。

## 快速上手

```bash
pnpm install          # 安装依赖
pnpm ollama:pull-chat # 下载 qwen3:8b（约 5.2GB，首次）
pnpm ollama:pull-embed # 下载 bge-m3（约 1.2GB，首次）
pnpm chroma:start     # 启动 Chroma（Docker）
pnpm kb index        # 构建向量索引
pnpm dev              # 启动前后端
```

> 详细说明见 [01 · 总览与架构](./01-overview.md)。
