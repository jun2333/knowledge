批注系统使用指南 ​

本文档介绍如何使用内置的批注系统，在阅读文档时直接添加、编辑和管理批注。

快速开始 ​

1. 添加批注 ​

  1. 选中文本：用鼠标选中你想批注的文字
  2. 点击按钮：在选区右上角会出现 "💬 添加批注" 按钮，点击它
  3. 输入内容：在弹出的对话框中输入你的批注、疑问或笔记
  4. 保存：点击"保存批注"按钮

选中的文本会自动添加黄色高亮背景，表示这里有批注。

2. 查看批注 ​

  • 鼠标悬停：将鼠标移到高亮文本上，会显示批注气泡
  • 点击高亮：点击高亮文本可以打开编辑对话框

3. 编辑批注 ​

  1. 点击高亮文本或批注气泡中的"编辑"按钮
  2. 修改批注内容
  3. 点击"保存修改"或"删除"

4. 管理批注 ​

页面左下角有一个绿色的批注面板按钮（右下角那个是 AI 助手）：

 批注 (5)  ← 显示当前页面的批注数量

点击后展开面板，可以看到：

  • 统计信息：总批注数、当前页面批注数
  • 导出功能：导出所有批注为 JSON 文件
  • 清空功能：清空所有批注（不可恢复）
  • 批注列表：当前页面的所有批注，点击可跳转到对应位置

高级功能 ​

导出批注 ​

如果你想把批注分享给我（AI 助手）：

  1. 点击左下角的批注面板按钮
  2. 点击"📥 导出所有批注"
  3. 浏览器会下载一个 annotations-{日期}.json 文件
  4. 把这个文件的内容复制粘贴到对话中，或者告诉我文件路径

JSON 格式示例：

json
[
  {
    "id": "anno-1234567890-abc123",
    "pageUrl": "http://localhost:5173/ai-agent/harness-engineering/core-concepts.html",
    "filePath": "/docs/ai-agent/harness-engineering/core-concepts.md",
    "selectedText": "Harness Engineering 解决的是工程闭环",
    "annotation": "这里的'工程闭环'具体指什么？能举个例子吗？",
    "createdAt": "2026-07-15T12:00:00Z",
    "updatedAt": "2026-07-15T12:00:00Z"
  }
]

批量处理 ​

如果你有很多批注需要我一起回答：

  1. 完成所有批注后，导出 JSON 文件
  2. 把 JSON 内容发给我，并说明："请帮我回答这些批注中的问题"
  3. 我会逐一回答每个批注

注意事项 ​

数据持久化 ​

  • 批注保存在浏览器的 LocalStorage 中
  • 同一浏览器：批注会一直保留，即使关闭页面再打开
  • 不同浏览器：批注不会同步（Chrome 的批注在 Firefox 看不到）
  • 清除缓存：如果清除了浏览器缓存，批注会丢失

建议：重要的批注记得导出备份！

适用范围 ​

  • 批注只在文章内容区域有效（.vp-doc 或 .VPDocContent）
  • 在导航栏、侧边栏等地方选中文本不会出现批注按钮

性能影响 ​

  • 批注系统对页面性能影响极小
  • 即使有几百条批注，也不会明显拖慢页面加载

常见问题 ​

Q: 为什么选中文本后没有出现批注按钮？ ​

A: 可能的原因：

  1. 选中的是导航栏、侧边栏等非文章内容区域
  2. 选中的文本太短（少于 2 个字符）
  3. 浏览器兼容性问题（建议使用 Chrome/Edge/Firefox 最新版）

Q: 批注气泡显示位置不对怎么办？ ​

A: 尝试刷新页面，批注位置会重新计算。如果问题持续存在，可能是页面布局特殊导致的，欢迎反馈。

Q: 如何删除某一条批注？ ​

A: 有两种方式：

  1. 点击高亮文本 → 在编辑对话框中点击"删除"
  2. 打开批注面板 → 每条批注右侧的 🗑️ 按钮可直接删除（会弹提示确认已删）

Q: 批注太多，面板很卡怎么办？ ​

A: 目前设计支持数百条批注，如果确实遇到性能问题：

  1. 定期导出不需要的批注
  2. 使用"清空所有批注"功能（谨慎操作）
  3. 反馈给我，我会优化性能

技术实现 ​

如果你对实现细节感兴趣：

  • 前端框架：Vue 3 Composition API
  • 数据存储：LocalStorage
  • 样式方案：Scoped CSS + Transition 动画
  • 核心文件（都在基座包 @minijun/kb-site 里，实例只再导出一行主题）：
    • theme/components/AnnotationSystem.vue - 主组件
    • theme/composables/useAnnotations.js - 数据逻辑
    • theme/Layout.vue - 布局注入（本地开发时才挂载）
    • theme/custom.css - 共享的遮罩 / toast 样式与层级变量
