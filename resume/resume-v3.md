## AI 项目实践（个人）

### DevAgent Harness — 面向软件开发的通用 AI 工作流引擎

**概述：** 为解决 AI Agent 开发时"输出不可控、经验不沉淀、难以复用"的痛点，设计并实现了一套面向软件开发的 AI 工作流引擎，让 Agent 按"计划→实现→验证→审查"的标准化流程执行开发任务。

**技术方案与核心设计：**

- 通过结构化 Prompt 与 YAML 工作流声明约束 Agent 行为，将开发过程拆分为可校验的阶段节点
- **Skill 体系**：将可复用的 AI 能力（测试生成、代码审查、文档撰写等）封装为标准 Skill，供不同任务按需组装
- **上下文加载策略**：按任务阶段动态注入上下文，解决长任务场景下 Agent 上下文窗口不足的问题
- **经验知识闭环**：将每次开发过程中的经验与教训自动沉淀，后续任务可直接复用

**可验证点：** 该引擎已完整驱动一个真实全栈项目（TaskFlow）从计划到交付的开发全过程；支持多 Agent 协同编排与技能扩展。

### RAG 知识库 — 个人知识库 AI 问答全链路

**概述：** 基于 pnpm Monorepo 架构，自建 VitePress 文档站 + Koa 后端服务，实现从文档索引构建、向量检索到 LLM 流式问答的完整链路。

**技术方案：** VitePress 文档站点 + Koa API 服务 + Chroma 向量数据库；文档构建阶段完成切分与向量化，问答阶段通过语义检索召回相关文档片段，接入 LLM 后以流式方式输出回答。

**可验证点：** 提供在线 Demo，支持现场演示"提问→检索→流式回答"完整链路（源码可查）。

### TaskFlow — AI 工作流驱动的真实项目验证（Next.js 全栈）

**概述：** 一个基于 Next.js 的全栈任务管理应用（Prisma + Playwright E2E），作为 DevAgent Harness 的实战验证项目。

**技术方案：** 全流程由自研的 Harness 工作流引擎驱动开发，从需求规划、代码实现、E2E 测试到代码审查均由 Agent 按标准化流程完成，验证工作流引擎在真实项目中的可用性与效率。

**可验证点：** 源码完整公开，E2E 测试覆盖核心流程。
